# Working on this project

Sibling project to `Rent Management Front-End` (the Next.js web app) and `Rent Management Back-End`
(the ASP.NET backend both apps talk to) — same owner, same backend, separate repo/codebase.

**Guided-coding mode**: same rule as the web app — the human wants to type the actual application
code themselves to learn React Native/Expo/TypeScript. Explain what file to create/edit, give the
exact code, and why — don't write application source files directly. (Scoped to `src/app/`,
`src/components/`, `src/lib/`, and similar source directories — updating docs/config, or this file
itself, is fine to do directly.)

**Canadian & Provincial Tenancy Law Compliance**: same standing requirement as the web app — see
`Rent Management Front-End/AGENTS.md` for the full PIPEDA/CASL/Ontario RTA/Manitoba RTA text. Applies
here too for any lease/deposit/rent-increase/notice/screening feature.
